# Titanic Survival Classification

This project explores whether a passenger's class, sex, age, and fare can predict
survival on the Titanic, using a logistic regression classifier trained on Kaggle Titanic data.

## Structure
- `data/` — dataset source info
- `proposal.md` — research question, dataset, and related work (on the `proposal` branch)
- `titanic_classification.ipynb` — data cleaning, model training, and evaluation
- `CONFLICT_NOTES.md` — documents a merge conflict and how it was resolved

## Technique
Binary classification (Logistic Regression) using scikit-learn.
